# 香港版本开发计划

## 项目目标
创建一个完全独立的"香港"版本，与现有"澳门"版本可同时运行。

## 文件结构

```
animal-number-ledger/
├── app.py                      # 澳门版启动（旧版，不修改）
├── app_hk.py                   # 香港版启动（新建）⭐
│
├── ui/
│   ├── main_window.py          # 澳门版UI（旧版，不修改）
│   ├── main_window_v2.py       # V2版UI（不修改）
│   └── main_window_hk.py       # 香港版UI（新建）⭐
│
└── 其他文件（共享，不修改）
```

## 技术方案

### 1. 数据库隔离
- 澳门版：使用 `ledger.db`
- 香港版：使用 `ledger_hk.db`
- 两个版本独立数据库，互不影响

### 2. 窗口标题区分
- 澳门版：`十二动物号码归纳器 v1.2.2`
- 香港版：`香港十二生肖投注系统 HK v1.0`

### 3. UI设计差异

#### 澳门版特点（现有）
- 传统布局
- 左右分栏
- 灰白色调

#### 香港版特点（新设计）
- 现代化设计
- 顶部标签页布局
- 蓝绿色调
- 大卡片展示
- 图表可视化

### 4. 业务逻辑
✅ 完全复用现有：
- parser.py - 解析逻辑
- calculator.py - 计算逻辑
- database.py - 数据库操作
- settlement.py - 结算逻辑
- constants.py - 常量定义

### 5. 文字替换
所有UI显示文字中的地域标识改为"香港"：
- 窗口标题
- 按钮文字
- 提示信息
