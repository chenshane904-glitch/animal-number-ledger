## 💡 主要差异

### 1. 数据库隔离

**澳门版：**
```
%APPDATA%/AnimalNumberLedger/ledger.db
```

**香港版：**
```
%APPDATA%/AnimalNumberLedger_HK/ledger_hk.db
```

### 2. UI布局

**澳门版：** 左右分栏布局
- 左侧：输入区域
- 右侧：结果显示（49行号码）

**香港版：** 标签页布局
- 输入页：专注输入
- 统计页：生肖卡片展示
- 结算页：开奖结算
- 历史页：记录查询
- 设置页：系统配置

### 3. 显示方式

**澳门版：** 显示49个号码，每个号码一行

**香港版：** 显示12个生肖卡片，每个卡片显示该生肖的所有号码

## 📝 使用示例

### 输入投注指令

切换到 **📝 输入** 标签页：


点击 **✅ 确认追加**，自动切换到 **📊 统计** 页查看结果。
