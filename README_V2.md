# 十二动物号码归纳器 V2.0

## 新版本特性

### 🎨 全新现代化UI设计

#### 卡片式布局
- **按动物分组显示**：不再按单个号码显示，而是按12个动物卡片展示
- **智能排序**：卡片按金额从大到小自动排序
- **一目了然**：每个动物卡片显示其所有号码和总金额

#### 视觉升级
- **现代化配色**：蓝色主题头部，清新的卡片设计
- **动物Emoji**：每个动物都有对应的表情符号，更生动
- **最高金额标识**：红色边框 + 淡红背景 + ⭐标记，一眼找到最高金额

#### 交互优化
- **大输入框**：输入区域更大，更方便
- **明显按钮**：绿色"开始计算"按钮，功能一目了然
- **点击查看详情**：点击任意动物卡片查看该动物所有号码的详细信息

### 📊 功能保留

所有旧版功能完整保留：

✅ 数字解析功能  
✅ 动物名称识别  
✅ 重复动物统计  
✅ 金额排序（金额最大排第一）  
✅ 最大金额红色高亮显示  
✅ 每日结算功能  
✅ 47倍赔率计算  
✅ 盈亏显示  
✅ 历史记录  
✅ 备份恢复  
✅ 跨日自动结算

### 💡 使用提示

1. **查看动物详情**：点击任意动物卡片，可以查看该动物下所有号码的详细下注记录

2. **快速找到最高金额**：带有红色边框和 ⭐ 标记的就是最高金额动物

3. **同一数据库**：新旧版本使用相同的数据库，可以随时切换

4. **测试新版本**：运行 `python test_ui_v2.py` 确认新旧版本不冲突

### ⚙️ 技术细节

- **框架**：customtkinter
- **布局算法**：按动物分组统计，金额排序
- **最大金额查找**：遍历12个动物的总金额
- **卡片渲染**：动态创建，支持滚动
- **颜色主题**：
  - 主色：`#2B5B84` (蓝色)
  - 成功：`#28A745` (绿色)
  - 警告：`#FFC107` (黄色)
  - 危险：`#DC3545` (红色)
  - 金色：`#D4AF37` (结算按钮)
