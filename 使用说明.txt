十二动物号码归纳器 v1.1.0 - 优化版
=====================================

版本信息
--------
版本号：v1.1.0（优化版）
发布日期：2026-07-23

优化内容
--------
✓ 数字字体全面加大（更易阅读）
  - 号码标签：14号加粗
  - 金额显示：16号加粗
  - 统计信息：14-16号加粗

✓ 最大金额红色高亮显示
  - 右侧结果区域中，金额最大的号码会显示红色边框
  - 自动识别并突出显示，一目了然

安装说明
--------
方法一：使用安装脚本（推荐）
1. 右键点击"install.bat"，选择"以管理员身份运行"
2. 按照提示完成安装
3. 选择是否创建桌面快捷方式

方法二：直接运行
1. 直接双击"十二动物号码归纳器-v1.1.0.exe"运行
2. 无需安装，可放在任意位置使用

卸载说明
--------
1. 右键点击"uninstall.bat"，选择"以管理员身份运行"
2. 确认卸载即可

数据位置
--------
程序数据保存在：
%LOCALAPPDATA%\AnimalNumberLedger\

注：卸载程序不会删除您的数据文件，可以手动删除上述目录

使用说明
--------
1. 在"输入指令"区域输入号码和金额（例如：1号0.50）
2. 查看"本次计算"区域的预览
3. 点击"确认追加"保存
4. 右侧结果区域会显示所有号码的累计金额
5. 金额最大的号码会用红色边框突出显示

功能特点
--------
✓ 支持1-49号码管理
✓ 自动计算和累计
✓ 历史记录查询
✓ 数据备份和恢复
✓ 自动跨日结算
✓ 动物号码映射
✓ 内置自检功能

技术支持
--------
如有问题，请检查：
1. 是否以管理员身份运行安装程序
2. 杀毒软件是否拦截
3. Windows版本是否为Windows 10/11

系统要求
--------
- 操作系统：Windows 10/11 (64位)
- 磁盘空间：至少20MB
- 内存：至少2GB
